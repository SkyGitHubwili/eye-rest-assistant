# 护眼助手 Windows 1.6.15

## 使用

- 点击窗口右上角“×”后隐藏到系统托盘，定时器和全屏休息提醒继续工作。
- 在右下角托盘区域（可能位于“显示隐藏的图标”中）双击护眼图标恢复窗口，也可右键选择“打开护眼助手”。
- 要彻底关闭软件，右键托盘图标选择“退出护眼助手”。
- 开机自启直接隐藏到托盘；后台休息结束后不再弹出设置主窗口。

## 兼容性

- 保留现有 Windows 界面和 Android 功能。
- 使用软件渲染并限制图片解码尺寸，改善双显卡、远程/虚拟显示器和大图片场景的稳定性。
- 设置保存在 `%LocalAppData%\护眼助手`；没有现有设置时，兼容读取旧目录中的设置。
- Windows 64 位单文件，包含 .NET 运行环境。升级前请从旧版本退出，再运行新版。

## 验证

- .NET 8 Release 构建及 Windows x64 单文件发布通过。
- 普通启动和开机启动两种模式的托盘检查通过：关闭隐藏、后台继续倒计时、恢复窗口、休息完成后保持隐藏并恢复计时、退出清理图标和计时器。
